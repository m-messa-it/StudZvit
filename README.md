# StudZvit — Веб-сервіс формування студентської звітності та документації

**StudZvit** — веб-сервіс автоматизованого формування звітної документації (зокрема звітів з практики, курсових та лабораторних робіт) за стандартами ДСТУ та вимогами навчальних закладів.

🔗 **Демонстраційна версія:** [https://m-messa-it.github.io/StudZvit/](https://m-messa-it.github.io/StudZvit/)

---

## 📌 Основний функціонал

1. **Конструктор звіту**
   - Вбудований покроковий генератор титульного аркуша.
   - Розділи роботи: індивідуальне завдання, щоденник практики, змістовна частина, висновки.
   - Модуль автоматичного формування списку використаних джерел.
   - Миттєвий попередній перегляд (Live Preview) макета А4.
   - Експорт звіту у формат Microsoft Word (`.docx`) та друк у PDF.

2. **Модуль перевірки тексту**
   - Нормоконтроль типографіки: автозаміна дефісів на тире (`—`), правильні лапки (`« »`), виправлення апострофів (`’`).
   - Контроль форматування: усунення зайвих пробілів, контроль абзацних відступів.
   - Стандарт розмітки: поля А4 (ліве 30 мм, праве 10 мм, верхнє 20 мм, нижнє 20 мм).

3. **Збережені чернетки**
   - Локальне збереження чернеток у браузері (`localStorage`) без ризику втрати прогресу.
   - Швидке завантаження та продовження роботи у будь-який час.

---

## 🛠 Стек технологій

- **Frontend:** HTML5, CSS3 (адаптивний інтерфейс, стилі друку `@media print`), Vanilla JavaScript.
- **Office Automation:** `docx.js`, `FileSaver.js`, `html2pdf.bundle.min.js`.
- **Backend / Microservices:** C#, ASP.NET Core Web API, RabbitMQ message broker.
- **Безпека:** Клієнтська обробка даних без передачі конфіденційної інформації на сторонні сервери.
