# StudDoc — Веб-сервіс формування студентської документації

Веб-застосунок для автоматизації створення титульних сторінок, звітів з практичних і лабораторних робіт та перевірки тексту на відповідність вимогам ДСТУ.

## Основні можливості
- Генератор титульних сторінок з попереднім переглядом формату А4 в реальному часі
- Конструктор структурованого звіту (тема, мета, обладнання, хід роботи, висновки, контрольні запитання)
- Модуль нормоконтролю тексту (автоматичне виправлення лапок, тире, пробілів, апострофів)
- Експорт сформованого документа у формат Microsoft Word (.docx)
- Друк та збереження у PDF безпосередньо з браузера
- Локальне збереження даних студента (localStorage) без потреби у зовнішній базі даних

## Стек технологій
- HTML5 / CSS3 / JavaScript (Vanilla JS)
- docx.js v8.5.0 (формування .docx на клієнті)
- FileSaver.js v2.0.5
